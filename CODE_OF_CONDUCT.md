# Code of Conduct

## Our standard

Participants are expected to be respectful, specific, and constructive. Critique code,
evidence, and assumptions without attacking people. Make room for different levels of
renewable-energy, machine-learning, and software experience.

## Unacceptable behaviour

Harassment, discrimination, intimidation, doxxing, credential sharing, and deliberately
misrepresenting measured results are not acceptable.

## Enforcement

Project maintainers may remove comments, close contributions, or restrict participation
when behaviour violates this standard. Report concerns privately through the repository’s
configured GitHub contact.
